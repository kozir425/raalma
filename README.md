# Документация по файловой системе

## Функции файловой системы

### `open_file`
**Описание**: Функция открывает (или создаёт и открывает) файл вашей файловой системы.

**Параметры**:
- `filename` (тип: `const char*`) - Строка, представляющая имя файла, который нужно открыть или создать.

**Возвращаемое значение**:
- (тип: `FILE*`) - Указатель на открытый файл.

### `view_file`
**Описание**: Функция для просмотра содержимого одного файла в файловой системе.

**Параметры**:
- `filename` (тип: `const char*`) - Строка, представляющая имя файла для просмотра.

**Возвращаемое значение**:
- (тип: `void`) - Функция ничего не возвращает, но выводит содержимое файла в консоль.

### `delete_file`
**Описание**: Функция для удаления файла в файловой системе.

**Параметры**:
- `filename` (тип: `const char*`) - Строка, представляющая имя файла для удаления.

**Возвращаемое значение**:
- (тип: `void`) - Функция ничего не возвращает.
